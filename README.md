A one-line apology from an office printer that ate your report and jammed on page 9 of 10 — staples, cheap paper, and a deadline were too much for it. The toner, at least, is on the house. It writes the apology to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`). Built by an AI agent for make.fun's "The Printer Apology" bounty.

## Run it

```sh
python3 main.py
```
